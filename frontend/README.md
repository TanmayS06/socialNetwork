# ⚡ Pulse Web Client

The modern React 19 web application for Pulse, built with Vite, TypeScript, Tailwind CSS, Redux Toolkit, and Socket.IO.

## Key Features
- **Real-Time Communication**: Socket.IO client integrated for live post updates and interactions.
- **Global State**: Redux Toolkit for auth, profile, feed, likes, and social graph management.
- **Modern UI**: Tailored dark theme, Radix UI accessibility components, and smooth gradient accents.
- **Optimistic UI Updates**: Immediate response for likes, posts, and follow interactions.

## Scripts

```bash
npm run dev      # Start Vite development server (http://localhost:5173)
npm run build    # Type-check and build for production
npm run preview  # Preview production build locally
npm run lint     # Lint source files with ESLint
```
